# Hymn catalog — licensor outreach exports

Plain-text exports of songs in `data/hymn_library.json` with inferred rights holders for licensing outreach.

**Note:** The catalog does not store official licenser metadata. Verify each title with JesCom / OneLicense / CCLI / the composer before relying on these for contracts.

## Files

| File | Description |
|------|-------------|
| `hymn_licensors_all.zip` | All exports in one zip |
| `hymn_licensors.txt` | Full detail, grouped by licensor |
| `hymn_licensors_simple.txt` | Tab-separated: title / author / licensor / sections |
| `hymn_licensors_jescom.txt` | JesCom titles |
| `hymn_licensors_ocp_onelicense.txt` | OCP / OneLicense titles |
| `hymn_licensors_gia_onelicense.txt` | GIA / OneLicense titles |
| `hymn_licensors_ccli.txt` | CCLI titles |
| `hymn_licensors_public_domain.txt` | Likely public-domain texts |
| `hymn_licensors_local_ph.txt` | Local Philippine composers / estates |
| `hymn_licensors.csv` | Spreadsheet-friendly CSV |
| `hymn_licensors.md` | Markdown version |
